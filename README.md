# Playlist Porter

A plugin for [SoundChex](https://github.com/tripsittr/SoundChex).

Bring your playlists with you. Import a playlist file (M3U, CSV, or XSPF) and it is matched to your library and saved as a SoundChex playlist, with anything it couldn't match listed for you to resolve. that adds an Import Playlist page to the admin, built on the porting engine the mobile app shares.

## Install

In SoundChex, open **Admin → System → Plugins → Browse plugins**, add the
SoundChex official repository (or this plugin's repository URL), then install and
enable **Playlist Porter**. A plugin runs as part of SoundChex with the server's access —
only install ones you trust.
